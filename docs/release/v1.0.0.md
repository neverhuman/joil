# joil 1.0.0

The first tagged release of joil: research software for evolving 3D-printable deoiling
cartridges, with the evidence that its results currently support. Nothing in it is
physically validated. `docs/STATUS.json` keeps `physical_validation`, `qualified_fitness`
and `qualified_capacity_gain` unset, and the README status table is generated from it.

## What it contains

- **Forge lane** ([`docs/forge/README.md`](../forge/README.md)): an open-ended
  process-network genome, genome-blind reduced-order judges for produced water and seawater
  spill duties, island evolution with a diversity archive, exact resume and seeding from
  earlier runs, an equal-budget random-search control, watertight CAD with a print audit,
  run reports, and fleet tooling (`fleet-summary`, `fleet-figures`).
- **Original lane**: the bounded liner genome, the `F1` screen, the OpenFOAM carrier-CFD
  pipeline with its same-pipeline `CT-35` control, the evidence kernel and the explorer app.
- **Claims audit**: every number in the README, the WHITEPAPER and `docs/RESULTS.md` traces
  to a committed receipt, or the build fails.

## Results in this release

- **Forge fleet run and its five-fold extension** (preregistered, `8` seeds, screen only):
  island evolution ranked above equal-budget random sampling of its own generator in all
  eight seeds at 768 384 and again at 3 840 384 evaluations per run (one-sided sign test
  p = 0.0039 each). Seeding from the last best design did not help (p = 0.9961). The
  winner, two cyclone stages with 13 cells in one 400 mm printed part, scores 3.133 in
  search and 3.040 at report resolution and stays feasible under eight further closure
  sets ([`docs/results/forge-v2-fleet-ext-winner-v1.json`](../results/forge-v2-fleet-ext-winner-v1.json)).
- **Original lane** (`F1` screen, sandbox): on repaired operators evolution does not beat
  uniform random search on the screen's best score (Wave-4), and the compiled CFD shells
  show no pressure-drop change against a same-pipeline `CT-35` (WHITEPAPER §4.6).

## Compatibility

The workspace crates and the explorer app move from `0.1.0` to `1.0.0`. Campaign files,
checkpoints and receipts are unchanged in format; Forge runs from earlier commits resume
exactly (`joil-forge/1.1.1`, `joil-forge-judges/1.0.0`). Historical receipts keep the
versions they recorded.

- Gates: `just required` passed locally on the release head (all ten suites, receipt kept

- Public content: `tools/check_public.py` passed, and the private deny rules found no hits

- Authorization: the owner asked for this release on 2026-10-22. No independent reviewer
  acknowledged the exact commit; the gates above and the claims audit are the review.

## Known limits

- Every Forge and `F1` number is a reduced-order screen result
  (`unvalidated_reduced_order_screen`, `F1`); no design has been printed or tested in water.
- No Forge design has been meshed for CFD; the original lane's CFD shells show no
  pressure-drop advantage over a same-pipeline `CT-35` (WHITEPAPER §4.6).
- No project software license has been selected; dependency licenses remain their own.

## Rollback
