# V5-04 / V5-08 serialized contract and lane split

This execution addendum preserves the existing tasks, acceptance criteria and
dependency order. The integrator owns root manifests, lockfile, shared contracts,
receipts acceptance, schemas and generated views. No physical campaign is enabled.

V5-04 depends on accepted V5-02/03. The integrator first registers `crucible-stats`
and its local dependency from `joil-core`, pins `statrs =0.18.0` without optional
random/linear-algebra features, and supplies checked quantiles and finite sample
moments. The cached release was checked against its own upstream manifest and
source; the pin is not a claim about the latest release. Independent t table and
Cauchy controls verify the consumed routine. These working foundations complete
no task by themselves: legacy adapter, applicability, clustering, joint inference,
tails and calibration still require their five ordered task receipts.

After an explicit tested contract handoff, the existing Claude worker owns
`crates/crucible-stats/src/analysis.rs` and its child modules,
`crates/crucible-stats/tests/` except `distribution_contract.rs`,
`crates/joil-core/src/experiment.rs`, and `tests/fixtures/v5-statistics/`.
The integrator retains `crates/crucible-stats/Cargo.toml`, `src/lib.rs`,
`src/distribution.rs`, `tests/distribution_contract.rs`, root manifests and lock.
Packet-local inference result types may live inside the owned analysis module;
new cross-packet shared types, dependencies or crate-root exports require a
serialized integrator contract before use. No worker edits progress/views/gates.

Code inspection found one necessary adapter-test scope omission: the existing
`p06_experiment_calibration_crossover_holdout_ct_and_comparator_gates` function in
`crates/joil-core/tests/regression.rs` expects the observed-effect power gate to
qualify without a prospective design. Once the replacement explicit-design API
contract is accepted, the statistics worker may update only this named function
to supply a declared synthetic pilot/effect protocol and test legacy refusal.
Every other function and item in that file stays byte-identical. This is a caller
migration for the repaired contract, not permission to weaken a positive check,
change a physical threshold or declare a protocol from confirmation outcomes.

V5-08 depends on accepted V5-03/05 and remains integrator-owned while Claude
implements V5-04. Its existing exact write scope remains authoritative. Crate
registration and any backend dependency pin precede the kernel comparison. A
candidate remains experimental and unadmitted outside measured coverage; failure
or unavailable applicability evidence is Unsupported/Unknown, not a physical fail
or an excuse to alter the CT-35 baseline.

All tests and temporary outputs stay in each worker's existing measured allocation.
Repeated synthetic statistical trials are bounded software verification, not an
evolutionary search or a physical campaign. Plans and resource caps are unchanged.
