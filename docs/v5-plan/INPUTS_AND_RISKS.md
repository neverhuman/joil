All statuses below start unresolved or proposed. No elapsed time or source example supplies approval. Preparing a protocol/adapter is permitted while an unrelated physical input is missing.

## Risk register

| Risk | Detection / stop | Owner and fallback |
| --- | --- | --- |
| Broad rewrite delays the first trusted result | M1 cannot run a nonempty durable fixture; M3 has no full baseline point | Integrator: reduce scope to native vertical slice; optional GPU/learned components stay deferred |
| Open grammar yields mostly failures | Charged mutation/compile yield by complexity/operator; planted invalid cases | Geometry/search: improve typed operators under a new policy; never hide failures or insert baseline |
| Partition/extraction mismatch | Volume/interface/deviation and topology disagreement | Geometry: reject unsupported backend or refine within lease; preserve artifact |
| Reference flow misses measured mechanisms | Variable-specific held-out discrepancy exceeds decision budget | CFD/validation: narrow applicability, acquire data or challenge model; no qualified ranking |
| Multiple stable states or state selection bias | Initial condition/ramp branches disagree beyond uncertainty | CFD/rig: retain branches; define startup/control requirement or report unresolved |
| Oil residence/closure/dispersion fails | Cohort residual, weighted uncertainty or wrong-drift negative fails | Oil owner: extend justified runs/model study within renewed lease; no captured-mass relabeling |
| Thin structures exploit approximate physics | Cross-mesh/load/imperfection/material checks change governing margin | Structural lead: conservative uncertainty and exact re-solves; do not rely on analytic yield screen |
| Accelerator/reduced operator misranks | Random audit false omissions, held-out profile/grade error or full-workflow cost | HPC/model owner: revoke authority, route full native reference, preregister smaller budget |
| Surrogate/descriptor drift or leakage | Family-grouped holdout/OOD coverage and archive crosswalk fail | Acquisition: disable ordering/pruning; keep random direct audits |
| Wrong inference unit or repeated attempts | Weighted/clustered/null coverage and inherited-family ledger checks | Statistics: reject invalid procedure; obtain fresh legitimate confirmation |
| Lost/partial durable state | Fault injection, verified restore and object closure | Runtime: recover last verified root; retain actual retry spend and disclose loss |
| Shared-host conflict or expired allocation | Lease/cpuset/RSS/disk monitoring | Runtime: stop only owned task groups; never kill/reprioritize another project |
| Existing journals/prototypes overwritten | Before/after dirty-path and byte-hash comparison | Integrator: separate checkout; preserve private patch; no reset/clean/stash of others’ work |
| Design disclosed through image/mesh | Disclosure classification/allowlist and public scan | Owner: keep private; no automatic export or legal conclusion |
| No positive discovery | Fair equal-cost independent controls win | Research: report negative result; retain qualified evaluator and explicit next experiment |

## Stop/resume contract

On a blocking event write packet/task ID, exact failed dependency or limit, subject/model/input identities, raw diagnostic/log digest, actual resource spend and next accountable action. Keep physical violation, numerical failure, unsupported capability, missing data and infrastructure failure separate. Never use a timeout as a physical label. Resume only when the named dependency is corrected with a new valid identity/receipt; elapsed time is not clearance.
