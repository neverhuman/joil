## 0. What the six reviews say (themes, deduplicated)

All six reviews (S1–S6) independently reach the same verdict: JOIL has a strong science stack (fidelity ladder,
OpenFOAM 14, red-team, MC, multi-seed, holdouts) but is **a curated exotic-parameter optimiser, not an open-ended
invention engine**, and several defects let it fool itself. Shared findings:

1. **Silent fallback to `baseline_ct35()`** on failed variation/normalisation corrupts lineage, operator stats, archive occupancy and validity tests (S1 §3.5, S2 §4.5, S3 P0-02, S4 §2.4, S5 P0.1, S6 §3.5).
2. **Schema identity erased** — v3 normalised back to v2 (S2 §4.6, S4 §2.5, S5 P0.2).
3. **Genome ≠ geometry**: Rust search mesh, Python B-rep, CFD mesh do not implement the same features (ribbons, TPMS, branches, skimmers); "6jet" may not be six paths (S1 §3.2, S2 §4.2, S3 P0-01/P0-06, S4 §2.2, S5 P0.3, S6 §3.3–3.4).
4. **Topology is an authored label**, not measured; 11 fixed families are anti-alien (S1 §3.3, S3 P0-12, S4 §2.9, S5 P0.6, S6 §3.2).
5. **Reduced-order evaluator is circular** — genome-derived mechanism descriptors feed the score that judges them (S1 §3.4, S2 §4.4, S3 P0-09, S4 §2.3, S5 P0.5, S6 §3.6). **This directly qualifies the Wave-3 10-seed "evolution proof" (reduced KPI) in PR #2 — it must be re-labelled as a search-efficiency result on a prior-laden screen, not physical evidence.**
6. **Structural verification bugs**: observed order uses `div_euclid`; load-transfer conservation constructed to zero; candidate loads not bound to hard constraint; "qualification" is an analytic screen (S1 §3.7, S3 P0-03/04/07, S5 §16, S6 §3.7).
7. **F0 facts asserted not measured**: `trapped_cavities: 0`, frozen-interface constants, arithmetic feature volumes (S2 §4.3, S3 P0-05, S6 App.A).
8. **Surrogate imputes defaults**, OOD not real; CUDA "parcel count" is tensor size (S1 §3.8–3.9, S2 §4.10, S5 P0.7, S6 §3.8).
9. **Requirements set not admitted**; runtime invents thresholds; preregistered objective ≠ executed; "hypervolume" isn't Pareto HV; MC tail quantiles over-read (S1 §3.6, S3 P0-11, S4 §2.6–2.8).
10. **"Expressiveness" 220/220 = closed-catalog validity**; rename (S2 §4.11, S5 P0.8).
11. **Target architecture** (all six): frozen question → open typed graph/developmental genome (v4) → deterministic DesignIR/GeometryIR compiler with dual backends (exact B-rep + SDF/voxel) → blind independent judge with typed observations & fidelity ladder F−1…F5 → Jarambit-style evidence/identity kernel, claim DAG, revocation, generated STATUS → QD search with multiple archives, emitters, measured descriptors → mechanism cards + counterfactual ablation → alienness as a vector, never a promotion score.

Migration sequences proposed: S1 §17 PR0–12, S2 §20 Milestones A–G, S3 §14 PR-XG-001…015, S4 §23 M0–M6, S6 §14 PR-0…11. **They agree that Milestone 0 ("truth repair / stop-the-line") must land before any further claim-bearing campaign.** This PR = M0 complete + M1/M2 foundations (evidence kernel, DesignIR v1 skeleton, measured F0) + honest docs. Full genome v4 / QD rewrite / physical F4 are follow-ons (§6).
