# Bounded geometry kernel

The shared implementation is `joil-geometry`; `crucible-geom` re-exports exactly those types for observers, mesh/export and genome consumers. One validated `FieldProgram` is the field identity. Coordinates use checked metres, constants are finite, references point backward and programs contain at most 4096 nodes. Every evaluation has a monotonically consumed operation budget. All nodes remain validated/evaluated and identity-bound, including unused nodes: failure never becomes a truncated baseline. Structural hashing normalizes signed zero and ignores independent node ordering while binding every operator, operand, literal and output.

The plain f64 interpreter remains the reference. The separately pinned experimental Fidget VM/JIT is a Linux x86_64 diagnostic prototype: at most 1024 nodes, finite f32 conversions, explicit tolerance, both candidate results checked against each other and the reference at every point. Unsupported arithmetic, precision collapse, overflow, exhausted budget or disagreement refuses that result. See the kernel decision for demonstrated coverage. Neither a pin nor finite sample agreement is a domain certificate.

Sphere, cuboid and capped-cylinder formulas have analytic distance semantics and global Lipschitz constant one in real arithmetic. Minimum/maximum booleans implement exact set union/intersection/difference, but their scalar values are not generally exact distances. Polynomial fillets and piecewise-linear chamfers carry conservative scalar error bounds, respectively width/4 and width/2 in addition to operand bounds. Converting a scalar error into a geometric displacement requires an admitted gradient lower bound; the API supplies none implicitly. Arbitrary algebra and Fourier fields have no admitted global distance bound. Floating evaluation can fail; distance claims require interval evaluation or another explicitly admitted certificate.

Intervals outward-round finite basic arithmetic and square roots, special-case squares, and refuse unproven square-root domains or overflow. Sine/cosine use the full [-1,1] mathematical enclosure; atan2 uses the full angular range. Affine forms retain linear coordinate dependence with interval coefficients; nonlinear terms fall back to a proven enclosure. Intersecting two enclosures preserves conservative bounds. Strictly negative/positive cells can be pruned; a zero-crossing cell remains unresolved. Clipped fluid volume is accumulated from proved cell owners, with every unclassified cell included in the upper bound and explicit ambiguous volume. Cell/operation exhaustion cannot be called an exact-distance proof. No re-distance backend is admitted. Finite-difference normals are diagnostic estimates; degenerate gradients and steps below coordinate resolution are refused.

`MaterialPartition` is the sole owner authority: outside the closed domain is void; inside it, nonpositive fluid field is fluid and the remainder solid. Fluid wins a zero tie. Frozen fluid/solid, ports, walls and keepouts are semantic regions with explicit owners, checked in both point and cell paths, independent of genome module labels. Derived consumers must have exactly one label and match this authority; independently filtered overlap/gap or frozen drift fails.

`ChamberWallProposal` is the checked wire contract used by the existing versioned wall-field recipe. The source inputs are bound to the exact frozen CT-35 genome/reference bytes. At most eight azimuthal modes of order 2..8, finite radial coefficients, twist within 2pi and the original summed 1.8mm amplitude envelope are allowed; no rounding or clipping changes a proposal. The analytic Fourier radius uses the original 20..65mm axial sine-squared band and twist. Its window is exactly zero outside the band in floating evaluation, retaining the original inlet, collar, reducing cone, 770mm taper and 700mm tail with 17.5mm terminal diameter. The intended analytic field is distinct from the old 13-section/128-sample CAD loft, whose approximation error remains unverified. Zero coefficients use the exact baseline field branch while keeping the distinct proposal digest.

Conformance is a single explicit majority-neighbour pass on a finite cubical artifact whose original labels were checked against the shared partition at their centres. The report computes actual relabel count, outward-rounded changed volume, conservative displacement, original/result identities and exact policy identity. Protected interface/feature witnesses cannot change; material components cannot disappear, split or merge; excessive changes and exhausted budgets are refused. This is a finite artifact contract: centre sampling does not establish continuous CAD equivalence or reveal an unsampled thin blade. Such claims remain unresolved and need independent artifact observation. No silent repair or physical admission is implemented.

Synthetic tests use hand geometry, independent polar Fourier samples, explicit interval samples, frozen-byte mutations, derived-owner overlap/gap controls, degenerate normals, precision collapse and a deliberately perturbed JIT result. Runtime logs and receipts remain immutable. TR-16, EV-09 and EV-12 remain deferred; this kernel grants no physical performance claim.
# Shared evaluation budgets

Finite-difference normals consume the same source-node allowance at every sample.
The reference interpreter charges every DAG node, including unused nodes. The
experimental checked Fidget backend charges three source passes per sample
(reference, VM, JIT); these are logical operations, not native instructions or a
wall-clock bound. An external backend that does not implement budgeted evaluation
is unsupported in budgeted algorithms. Failed charges exhaust the allowance and
cannot refill it. A three-node plane therefore needs eighteen operations for its
six-sample normal, even though its analytic normal is trivial.
